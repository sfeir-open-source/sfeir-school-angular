# `@if` — conditional rendering

Render a block only when a condition is truthy. Add `@else if` / `@else` branches as needed:

<br/>

```html
@if (user().isAdmin) {
  <admin-panel />
} @else if (user().isMember) {
  <member-area />
} @else {
  <p>Please sign in.</p>
}
```

<!-- .element: class="big-code" -->

Notes:

- `@if` is built into the template compiler — no `CommonModule`, no `*ngIf` import.
- Only the matching branch is created in the DOM; the others are removed entirely.

##==##

# `@if` with an alias (`as`)

Capture the condition's value into a local variable with `as` — handy to avoid re-reading a signal or calling a function twice:

<br/>

```html
@if (currentUser(); as user) {
  <p>Welcome, {{ user.name }} ({{ user.role }})</p>
}
```

<!-- .element: class="big-code" -->

Notes:

- The alias is only in scope inside the block.
